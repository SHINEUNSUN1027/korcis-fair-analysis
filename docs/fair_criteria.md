# FAIR 원칙 15개 항목별 판정 기준

> 이 문서는 논문 「FAIR 원칙에 따른 한국 고문헌 메타데이터 관리체계 진단」의  
> 〈표 5〉 KORCIS FAIR 준수도 평가 및 〈표 6〉 해외 사례 비교의 판정 근거를 명시합니다.

---

## 판정 등급 정의

| 등급 | 기호 | 정의 |
|------|------|------|
| **적합** | ✅ | 항목의 요건을 데이터 구조 및 시스템 기능 차원에서 실질적으로 충족 |
| **부분 적합** | 🔶 | 일부 요건을 충족하나 핵심 요건이 제한적으로 이행됨 |
| **미흡·결여** | ❌ | 요건 충족을 위한 구조적 조건이 부재하거나 이행 수준이 극히 낮음 |

판정은 ① 전체 데이터의 구조적 특성, ② 시스템 차원의 기능 지원 여부, ③ 정량 분석 결과(출현율·기재율)를 종합하여 수행하였습니다. 개별 레코드의 내용적 정확성은 판정 범위에 포함하지 않습니다.

---

## F — Findable (발견 가능성)

### F1. 메타데이터 및 데이터에 전 지구적으로 고유하고 영구적인 식별자 부여

**판정 기준**:
- 적합: 모든 서지 레코드에 HTTP URI, DOI, ARK, PURL 등 국제적으로 통용되는 영구 식별자 체계 적용
- 부분 적합: 일부 레코드에 영구 식별자 적용, 또는 기관 내부에서만 유효한 고유 번호 체계 존재
- 미흡·결여: 영구 식별자 체계 부재; 내부 제어번호만 존재하며 외부 시스템에서 직접 참조 불가

**KORCIS 판정 근거**:
- 001 필드 내부 제어번호: OLDP형(3,754건), 기관코드형(183,039건), 기타(380,419건)로 체계 미통일
- HTTP URI·DOI·ARK·PURL 형식의 식별자: **0건 확인**
- **판정: ❌ 미흡·결여**

---

### F2. 메타데이터를 풍부하게 기술

**판정 기준**:
- 적합: 필수·선택 필드 전반의 완성도가 높고, 기계 가독성을 갖춘 국제 표준 어휘로 기술
- 부분 적합: 필수 필드 완성도는 높으나 선택 필드 편차가 크거나 국제 표준 어휘 미사용
- 미흡·결여: 필수 필드조차 대규모 누락, 또는 메타데이터 기술 자체가 부실

**KORCIS 판정 근거**:
- 필수 필드(245·300·260) 출현율: 99% 이상으로 높음
- 선택 필드: 650(27.35%), 100(38.86%), 856(1.49%) 등 낮고 기관 간 편차 극심
- 국제 표준 어휘(LCSH·VIAF URI 등) 미적용; 자유 텍스트 중심 기술
- **판정: 🔶 부분 적합**

---

### F3. 메타데이터가 데이터 식별자를 명확히 포함

**판정 기준**:
- 적합: 메타데이터 레코드가 해당 디지털 객체(원문)의 영구 식별자를 명확히 포함
- 부분 적합: 일부 레코드에 원문 URL이 포함되나 영구 식별자 형식이 아님
- 미흡·결여: 데이터 식별자 포함 구조 자체가 부재

**KORCIS 판정 근거**:
- 856 필드(원문 접근 URL) 출현율: 1.49%(8,467건) — 98.5% 레코드에 원문 링크 없음
- 포함된 URL도 기관 내부 서버 임시 URL이 대부분; 영구 식별자 형식 0건
- **판정: ❌ 미흡·결여**

---

### F4. 메타데이터가 검색 가능한 자원에 등록 또는 인덱싱

**판정 기준**:
- 적합: 공개 검색 엔진 또는 메타데이터 수확 프로토콜(OAI-PMH 등)을 통해 외부 인덱싱 가능
- 부분 적합: 웹 검색 인터페이스를 통한 접근은 가능하나 기계적 수확 프로토콜 미지원
- 미흡·결여: 웹 인터페이스조차 외부 인덱싱을 허용하지 않거나 접근 자체가 제한

**KORCIS 판정 근거**:
- KORCIS 웹 검색(https://www.nl.go.kr/korcis)을 통한 인간 접근 가능
- OAI-PMH, API, SPARQL 엔드포인트: **모두 미지원**
- 공공데이터포털 파일 배포는 존재하나 실시간 인덱싱 구조 아님
- **판정: 🔶 부분 적합**

---

## A — Accessible (접근 가능성)

### A1. 메타데이터 및 데이터가 표준화된 통신 프로토콜로 식별자를 통해 검색 가능

**판정 기준**:
- 적합: HTTP(S) 기반 REST API 또는 SPARQL 엔드포인트를 통해 식별자로 개별 레코드 조회 가능
- 부분 적합: 웹 인터페이스를 통한 검색 가능하나 기계적 접근(API 등) 미지원
- 미흡·결여: 식별자 기반 접근 불가; 전체 파일 다운로드만 가능

**KORCIS 판정 근거**:
- HTTPS 웹 검색 인터페이스 제공 — 인간 접근은 가능
- REST API·SPARQL 엔드포인트: **미제공**
- 식별자(제어번호)를 URL에 삽입하여 개별 레코드를 직접 조회하는 구조 없음
- **판정: 🔶 부분 적합**

---

### A1.1. 프로토콜이 개방적이고 무료이며 보편적으로 구현 가능

**판정 기준**:
- 적합: HTTP(S) 등 국제 표준 오픈 프로토콜 사용
- 미흡·결여: 독점 프로토콜 또는 유료 접근 요구

**KORCIS 판정 근거**:
- 웹 인터페이스는 표준 HTTPS 사용 — 프로토콜 자체는 개방적
- 그러나 기계적 접근 수단(API) 부재로 실질적 활용 제한
- **판정: 🔶 부분 적합** (A1과 연동 평가)

---

### A1.2. 프로토콜이 필요한 경우 인증 및 권한 절차를 지원

**판정 기준**:
- 적합: 공개 데이터에 인증 없이 접근 가능; 또는 표준화된 인증 절차 존재
- 미흡·결여: 접근 정책 미명시 또는 불필요한 접근 장벽 존재

**KORCIS 판정 근거**:
- 웹 검색은 비회원 접근 가능; 공공데이터포털 파일은 회원가입 후 다운로드
- 접근 정책 명시 문서 부재
- **판정: 🔶 부분 적합**

---

### A2. 메타데이터가 데이터 자체에 접근 불가한 경우에도 접근 가능

**판정 기준**:
- 적합: 원문 이미지 제공 여부와 무관하게 서지 메타데이터에 독립적 접근 보장; 장기 보존 계획 명시
- 미흡·결여: 메타데이터의 장기 접근성 보장 정책 또는 구조 부재

**KORCIS 판정 근거**:
- 서지 메타데이터는 공공데이터포털에 별도 파일로 공개 — 원문과 독립 접근 가능
- 그러나 영구 식별자가 없어 특정 레코드의 지속적 접근 보장 불가
- 메타데이터 장기 보존 정책 명시 문서 미확인
- **판정: ❌ 미흡·결여**

---

## I — Interoperable (상호운용성)

### I1. 메타데이터 및 데이터가 지식 표현을 위한 공식적이고 접근 가능하며 공유·적용 가능한 언어를 사용

**판정 기준**:
- 적합: RDF/OWL/JSON-LD 등 시맨틱 웹 표준 형식으로 데이터 제공
- 부분 적합: XML 등 구조화 포맷 사용하나 의미적 관계 표현 불가
- 미흡·결여: 텍스트 기반 평면 구조; 기계적 의미 추론 불가

**KORCIS 판정 근거**:
- KORMARC XML 형식 제공 — 구조적 포맷이나 RDF 기반 의미 표현 불가
- 주희(朱熹)·주자(朱子) 등 동일 인물의 이표기를 시스템이 동일 개체로 인식 불가
- RDF·JSON-LD 형식 제공: **없음**
- **판정: ❌ 미흡·결여**

---

### I2. 메타데이터 및 데이터가 FAIR 준수 어휘를 사용하여 기술

**판정 기준**:
- 적합: LCSH·VIAF·GeoNames 등 국제적으로 통용되는 통제 어휘 또는 온톨로지 적용
- 부분 적합: 국내 통제 어휘(KAC 전거 등)는 일부 적용되나 국제 표준 어휘 미적용
- 미흡·결여: 통제 어휘 미적용; 자유 텍스트 중심 기술

**KORCIS 판정 근거**:
- KAC 국립중앙도서관 인명전거 연계: 1,600건(0.28%) — 사실상 미적용 수준
- LCSH·VIAF URI 등 국제 표준 어휘: **0건**
- 판본 유형(木板本·목판본·木版本 등) 혼용 확인 — 통제 어휘 미적용
- **판정: ❌ 미흡·결여**

---

### I3. 메타데이터 및 데이터가 다른 메타데이터·데이터에 대한 정규화된 참조를 포함

**판정 기준**:
- 적합: owl:sameAs 등을 통해 VIAF·Wikidata·LCNAF 등 외부 전거 URI와 명시적 연결
- 부분 적합: 국내 전거 시스템과의 연계는 일부 존재하나 국제 전거 연계 없음
- 미흡·결여: 외부 전거 연계 전무; 내부 텍스트 값만 존재

**KORCIS 판정 근거**:
- KAC 전거번호 연계(0 식별기호): 100 필드 기준 0.73%, 700 필드 기준 0.68%
- VIAF·Wikidata·LCNAF URI 연계: **0건 확인**
- **판정: ❌ 미흡·결여**

---

## R — Reusable (재사용 가능성)

### R1. 메타데이터 및 데이터가 다양한 속성으로 풍부하게 기술

**판정 기준**:
- 적합: 데이터 생산 맥락, 출처, 수집 방법 등 출처 정보(provenance)가 메타데이터에 포함
- 부분 적합: 기본 서지 정보는 충실하나 출처 메타데이터 및 이력 정보 미흡
- 미흡·결여: 출처·이력 정보 체계적 기술 없음

**KORCIS 판정 근거**:
- 기본 서지 필드(245·300·260) 완성도 높음
- 데이터 생산·수정 이력, 입력 기관 정보 등 출처 메타데이터의 체계적 기술 미확인
- **판정: 🔶 부분 적합**

---

### R1.1. 메타데이터 및 데이터가 명확하고 접근 가능한 데이터 사용 라이선스를 보유

**판정 기준**:
- 적합: 개별 레코드 또는 전체 데이터셋에 표준화된 라이선스(CC0·CC BY 등) 명시
- 부분 적합: 공공데이터포털 배포본에 공공누리 라이선스 적용되나 개별 레코드에 미명시
- 미흡·결여: 라이선스 정보 전혀 없음

**KORCIS 판정 근거**:
- 공공데이터포털 공개 데이터: 공공누리 제1유형 적용 확인
- KORCIS 웹 서비스 레코드 단위 라이선스 표시: **미확인**
- 메타데이터 내 라이선스 필드 기재: **0건**
- **판정: 🔶 부분 적합**

---

### R1.2. 메타데이터 및 데이터가 상세한 출처 정보와 연결

**판정 기준**:
- 적합: 데이터의 생산자·수집 일시·입력 방법 등 출처 이력이 메타데이터에 명시
- 미흡·결여: 출처 이력 정보 체계적 기술 없음

**KORCIS 판정 근거**:
- 도서관부호·도서관명 필드를 통해 소장 기관 식별 가능 — 출처 기관 추적 가능
- 입력 일시·수정 이력 등 데이터 생산 출처 정보: **미확인**
- **판정: ❌ 미흡·결여**

---

### R1.3. 메타데이터 및 데이터가 도메인 관련 커뮤니티 표준을 충족

**판정 기준**:
- 적합: BIBFRAME·EDM 등 국제 도서관·문화유산 표준과 정렬됨
- 부분 적합: KORMARC 등 국내 표준을 준수하나 국제 표준과 미정렬
- 미흡·결여: 국내 표준조차 일관되게 적용되지 않음

**KORCIS 판정 근거**:
- KORMARC 기반 기술 — 국내 도서관 표준 준수
- BIBFRAME 2.0·Europeana EDM 등 국제 표준과의 정렬: **미이행**
- **판정: 🔶 부분 적합**
