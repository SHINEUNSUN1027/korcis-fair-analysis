# 분석 변수 설명 (Codebook)

## parsed_records.csv

`01_parse_kormarc.py` 출력 파일. 레코드 1건 = 1행.

| 변수명 | 유형 | 설명 |
|--------|------|------|
| `record_key` | str | KORCIS 내부 레코드 식별자 (001 필드) |
| `library_code` | str | 소장 기관 도서관 부호 |
| `library_name` | str | 소장 기관명 |
| `has_100` | bool | 기본표목-개인명(100) 필드 존재 여부 |
| `has_245` | bool | 서명저자사항(245) 필드 존재 여부 |
| `has_250` | bool | 판사항(250) 필드 존재 여부 |
| `has_260` | bool | 간사사항(260) 필드 존재 여부 |
| `has_300` | bool | 형태사항(300) 필드 존재 여부 |
| `has_600` | bool | 주제명부출-개인명(600) 필드 존재 여부 |
| `has_650` | bool | 일반주제명(650) 필드 존재 여부 |
| `has_651` | bool | 지명주제(651) 필드 존재 여부 |
| `has_653` | bool | 비통제 색인어(653) 필드 존재 여부 |
| `has_700` | bool | 부출표목-개인명(700) 필드 존재 여부 |
| `has_856` | bool | 전자적 위치 및 접속(856) 필드 존재 여부 |
| `has_auth_100` | bool | 100 필드에 전거번호(0 식별기호) 기재 여부 |
| `has_auth_700` | bool | 700 필드에 전거번호(0 식별기호) 기재 여부 |
| `has_auth_650` | bool | 650 필드에 전거번호(0 식별기호) 기재 여부 |
| `auth_no_100` | str | 100 필드 전거번호 값 (복수 시 \| 구분) |
| `auth_no_700` | str | 700 필드 전거번호 값 |
| `auth_no_650` | str | 650 필드 전거번호 값 |
| `urls_856` | str | 856 필드 URL 값 (복수 시 \| 구분) |
| `url_count` | int | 856 필드 URL 수 |
| `morphology_codes` | str | 300$b 형태코드 (02=광곽, 04=계선, 07=판구, 08=어미) |
| `edition_type` | str | 250$a 판종류 텍스트 값 |

## field_frequency.csv / table3_field_frequency.csv

`02_field_analysis.py` 출력 파일.

| 변수명 | 설명 |
|--------|------|
| `태그` | KORMARC 태그 번호 |
| `필드명` | 한국어 필드명 |
| `필드유형` | M(필수) / MA(해당시 필수) / O(재량) |
| `출현건수` | 해당 태그가 기재된 레코드 수 |
| `출현율(%)` | 전체 567,212건 대비 비율 |
| `비고` | 해석 시 유의사항 |

## institution_quality.csv / table4_institution.csv

`02_field_analysis.py` 출력 파일. 소장 건수 상위 10개 기관.

| 변수명 | 설명 |
|--------|------|
| `기관명` | 소장 기관명 |
| `소장건수` | 해당 기관 레코드 수 |
| `비율(%)` | 전체 대비 비율 |

| `250(판사항) 출현율(%)` | 해당 기관 내 250 필드 출현율 |
| … | 각 태그별 동일 구조 |

## table5_fair_evaluation.csv

| `근거_정성` | 판정의 정성적 근거 (구조적 설명) |
| `개선방향` | 권고 개선 사항 |
